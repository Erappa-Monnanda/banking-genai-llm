# Banking GenAI: LLM Applications

LLM applications for fraud investigation, built with the
Groq API and LangChain.

## Notebooks
| Notebook | What it covers |
|---|---|
| `llm_fundamentals.ipynb` | Groq API, temperature, system prompts, zero-shot/few-shot/JSON output, fraud alert summarizer |
| `langchain.ipynb` | Prompt templates, LCEL pipe operator, output parsers, 3-step investigation chain |
| `Sequential_chain.ipynb` | Sequential chain: classify, report, action plan |
| `LLM_Memory.ipynb` | Buffer, window and summary memory, with a test showing window memory hallucinating |
| `Embeddings.ipynb` | Sentence embeddings, cosine similarity, ChromaDB |

## Skills shown
Prompt engineering, LangChain, structured JSON output,
conversation memory, embeddings, vector databases
